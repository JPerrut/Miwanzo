# Miwanzo

Estrutura atual do repositório:

- `backend`: API Node.js/Express com Prisma e PostgreSQL
- `frontend`: aplicação web React com Vite
- `mobile`: espaço reservado para a futura aplicação mobile

Comandos principais na raiz:

- `npm run dev`: sobe frontend e backend juntos
- `npm run dev:frontend`: sobe apenas o frontend
- `npm run dev:backend`: sobe apenas o backend
- `npm run build:frontend`: gera o build do frontend
- `npm run lint:frontend`: valida o frontend
- `npm run lint:backend`: valida o backend
- `npm run test:backend`: executa os testes do backend
- `npm run setup`: instala dependências e executa o setup do banco no backend

Arquivos de ambiente:

- `frontend/.env`: variáveis do Vite
- `backend/.env`: variáveis do backend
